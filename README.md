1. Configurar o banco de dados

Inicie Apache e MySQL no XAMPP.

Acesse http://localhost/phpmyadmin/.

Crie um banco de dados chamado crud_php.

Selecione o banco criado.

Clique em Importar.

Selecione o arquivo banco.sql disponível no projeto.

Execute a importação.

2. Configurar a conexão

Na pasta config, copie o arquivo conexao.exemplo.php e renomeie a cópia para conexao.php.

Configure o usuário e a senha do MySQL de acordo com seu ambiente.

3. Executar o sistema

Abra o navegador e acesse:

http://localhost/crud-php/
